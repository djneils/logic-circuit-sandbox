# Logic Circuit Sandbox

Build logic circuits from AND, OR, NOT and XOR gates and see the expression and truth table update as you go. Includes twelve challenges (OCR A Level Computer Science, H446).

## Features

### Building
- Drag gates onto the board and wire pins together
- Click switches to change inputs
- Live Boolean expression and truth table for the circuit
- Unconnected inputs are highlighted

### Challenges
- Warm-ups with AND, NOT and OR
- Three inputs, brackets matter, seatbelt warning, voting judges
- Simplify first, XOR from scratch, De Morgan's law, not every input is needed
- Half adder and full adder
- Gate limits on each challenge, and a **Check circuit** button
- Free build mode

## How to Use

1. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari). Nothing to install, no login.
2. Choose a challenge (or **Free build**)
3. Drag gates onto the board and connect them
4. Press **Check circuit**

## Use Cases

- A first practical on logic gates
- Seeing how circuits, expressions and truth tables connect
- Extension work with the harder challenges

## Tech

- A single HTML file: HTML, CSS and plain JavaScript
- No libraries, no build step, no backend
- Uses the browser's local storage to remember your progress
- Light and dark themes
